# Configuration

RetailOps Kiosk reads `window.__KIOSK_CONFIG__` before the app starts.

The committed `index.html` contains safe defaults and a placeholder API key.
Real station configuration belongs in `config.local.js`.

## Create Local Config

```bash
cp config.example.js config.local.js
```

Then edit `config.local.js`.

## Required Fields

| Field | Description |
| --- | --- |
| `BASE_URL` | RetailOps Backend origin, without `/api/v1`. |
| `API_PATH` | API path. Default: `/api/v1`. |
| `KIOSK_API_KEY` | Per-station key generated by RetailOps Backend. |
| `STORE_NAME` | Display name shown in the kiosk header. |
| `STORE_ADDRESS` | Store address shown in receipts and summaries. |
| `KIOSK_STATION_NUMBER` | Station number shown in the UI/receipt. |
| `ENABLED_PAYMENT_METHODS` | Payment methods visible in the kiosk. |

Example:

```js
window.__KIOSK_CONFIG__ = {
  BASE_URL: "http://127.0.0.1:8000",
  API_PATH: "/api/v1",
  KIOSK_API_KEY: "<KIOSK_API_KEY>",
  STORE_NAME: "RetailOps Kiosk",
  STORE_ADDRESS: "Local store",
  KIOSK_STATION_NUMBER: "1",
  ENABLED_PAYMENT_METHODS: ["cash", "mobile_payment", "bank_transfer"],
  APP_VERSION: "2.1.0",
};
```

## Optional Fields

| Field | Default | Description |
| --- | --- | --- |
| `BRAND_LOGO_URL` | empty | Local or HTTPS logo URL. |
| `BRAND_LOGO_ALT` | store name | Logo alt text. |
| `BRAND_SUBTITLE` | `autopago` | Small subtitle below brand name. |
| `BRAND_SHOW_TEXT` | `true` | Show text next to the logo. |
| `KIOSK_THEME` | blue RetailOps palette | Theme color map. |
| `USD_TO_BS_RATE` | `1` | Static fallback exchange rate. |
| `EXCHANGE_RATE_API_URL` | empty | Optional live exchange-rate endpoint. |
| `CURRENCY_SYMBOL` | `Bs.` | Local currency symbol. |
| `DECIMAL_PLACES` | `2` | Local currency decimal places. |
| `LOW_STOCK_THRESHOLD` | `5` | Low-stock marker in product search. |
| `LOCALE` | `es-VE` | Browser locale for formatting. |
| `IDLE_TIMEOUT_SECONDS` | `120` | Idle session reset timeout. |
| `PROCESSING_TIMEOUT_SECONDS` | `60` | Payment processing timeout. |
| `BARCODE_ENABLED` | `false` | Enables scanner input on product screen. |
| `APP_VERSION` | `1.0.0` | App version used for service worker cache busting. |

## Payment Methods

Supported values depend on backend settings. Current kiosk UI supports:

```js
["cash", "mobile_payment", "bank_transfer"]
```

`mobile_payment` and `bank_transfer` can require receipt upload and OCR-backed
field matching if the backend is configured that way.

## Cache And Updates

The service worker caches app assets for fast loading. When changing versioned
app files, increment `APP_VERSION` in `config.local.js` and `CACHE_VERSION` in
`sw.js`.

`config.local.js` is never cached by the service worker, so station config and
API key changes can take effect without clearing browser cache.
