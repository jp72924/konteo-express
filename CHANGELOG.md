# Changelog

## 2.1.0 - Initial Public Release

- Publish RetailOps Kiosk as a standalone self-checkout PWA.
- Support per-station configuration through `config.local.js`.
- Connect to RetailOps Backend using `Authorization: KioskKey <key>`.
- Provide one-command installers for Linux/macOS and Windows.
- Include public setup, configuration, backend integration, branding, security,
  and contribution documentation.
- Keep the project dependency-free: vanilla HTML, CSS, and JavaScript modules.
